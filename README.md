# 治愈蜡笔彩铅插画

把照片、截图或现有画作转成低饱和、柔和、带纸张颗粒感的治愈系蜡笔彩铅插画。

## 适用情形

- 照片转可爱手绘风
- 人像、宠物、亲子或人宠互动
- 静物、花艺和室内生活场景
- 用户说“转成这种风格”“做成治愈插画”“蜡笔风”“彩铅风”或“可爱插画风”

## 用法

上传一张图片，并提出类似下面的要求：

> 把这张图转成治愈蜡笔彩铅插画风格，保留主体和动作，温柔可爱一点。

技能会根据原图的主体、构图和场景，自动选择合适的文字化风格规则。完整工作流见 [SKILL.md](SKILL.md)。
